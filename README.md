# Peraravatar

PNG画像を切り替えるだけのシンプルな PNGTuber（バーチャル顔出し）ツールです。OBS のブラウザソースに読み込むだけで動きます。

- マイク音量に応じた口パク（段階数は自由に増減）
- 自動瞬き／呼吸／左右揺れ／首かしげ
- アイドル時のよそ見（左右の画像を指定可能）
- 驚き顔（Space キー or 大声で発火、ホップ/リコイル切替）
- ねむい状態（長時間無音で呼吸が浅くなり、瞬きがゆっくりになる）
- 設定はブラウザ内 localStorage に自動保存
- JSON で設定書き出し/読み込み

---

## クイックスタート

### 1. ローカルサーバーを起動する

`getUserMedia`（マイクアクセス）は `file://` だと動かないため、ローカル HTTP サーバー経由で開く必要があります。お好みの方法を選んでください：

| 方法 | bat | 前提 |
|---|---|---|
| Python | `server-python.bat` をダブルクリック | Python が必要 |
| Node.js | `server-node.bat` をダブルクリック | Node.js が必要 |

どちらもインストール済みなら片方でOKです。bat を起動するとコマンドプロンプトが開いたままになります（**閉じるとサーバーも止まります**）。

### 2. ブラウザで開く

bat 起動後、ブラウザで以下を開きます：

```
http://localhost:8765/
```

初回はパネルしか出ません。「画像」タブから自分のアバター画像を設定してください。

### 3. OBS への組み込み

OBS Studio で「ブラウザソース」を追加し、以下を設定します：

- URL: `http://localhost:8765/`
- 幅 × 高さ: 任意（推奨 600×900 など、画像のアスペクト比に合わせる）
- 「ローカルファイル」: チェックしない（URL を使う）

**ブラウザソースからマイクを使うための重要設定**: OBS は起動時オプションとして以下のフラグが必要です。OBS のショートカット（デスクトップ等）を右クリック → プロパティ → 「リンク先」を次のように編集してください：

```
"C:\Program Files\obs-studio\bin\64bit\obs64.exe" --use-fake-ui-for-media-stream --autoplay-policy=no-user-gesture-required
```

「作業フォルダー」が空の場合は `C:\Program Files\obs-studio\bin\64bit` を設定。

このフラグがないと、ブラウザソースのマイク許可が永遠に降りません。

### 4. 配信パネルを隠す

「設定」タブで「OBS用に起動時パネル非表示」にチェックを入れると、次回読み込み時にパネルが自動で隠れます。再表示は **H キー** で可能（OBS で見えてる状態でブラウザソースにマウスフォーカスがある時のみ反応）。

または URL に `?panel=0` を付ければ強制的に非表示にできます。

## Python / Node.js のインストール

どちらか一方で OK です。慣れている方を使ってください。

### Python（推奨：簡単）

公式: <https://www.python.org/downloads/>

1. 上記から Windows installer をダウンロード
2. インストーラ起動 → **「Add Python to PATH」にチェック** → 「Install Now」
3. 完了後、PowerShell や cmd で `python --version` が動けば OK

### Node.js

公式: <https://nodejs.org/>

1. LTS 版インストーラをダウンロード
2. デフォルト設定でインストール（PATH 設定もチェックされてる）
3. 完了後、`node --version` と `npx --version` が動けば OK

## 使い方

### 画像タブ

**固定スロット**（クリックでファイル選択）:
- **通常**: 何もしていない時の標準顔
- **瞬き(閉眼)**: 目を閉じた状態
- **驚き**: Space キーや大声で発火
- **よそ見(左)**: アイドル時に左を見る画像（任意）
- **よそ見(右)**: アイドル時に右を見る画像（任意）

**口パク（音量ごとの段階）**:
- 各段階に「音量がいくつ以上で発火するか」の閾値スライダーを設定
- 各段階に画像を1枚以上アップロード（複数枚を入れると自動でランダム切替＝口元のバリエーション）
- 「+ 口パク段階を追加」で段階を増減可能
- 段階数は1〜任意（よくある構成: 小=「い」/中=「い大きめ」/大=「あ」など）

例：
- 段階1: 閾値 5、画像 [小さい口]
- 段階2: 閾値 8、画像 [中くらいの口]
- 段階3: 閾値 12、画像 [大きい口1, 大きい口2]（ランダム）

### 音声タブ

- **音量メーター**: マイクの現在音量（0〜100）
- **びっくり音量**: この値を超えると驚き顔発火（モード次第）
- **発火モード**:
  - ワンショット: 一度発火したら 0.6 秒だけ表示、クールダウンあり
  - ホールド: 大声が続いている間ずっと表示
  - 音量で発火しない: Space キーだけで発火
- **驚きの動き**: ホップ（上に跳ねる）/ リコイル（後ろに引く）

### 動きタブ

呼吸／揺れ／首かしげ／視線揺れ／ズームパルス／驚き／よそ見／ねむいモード、それぞれを微調整可能。すべてリアルタイムに反映されます。

### 動作タブ

- **無音とみなす上限 (threshold1)**: これ以下では完全に「閉じ」
- **大開き開始 (threshold2)**: これ以上では最大段階の口パク
- **瞬き**: 間隔と閉眼時間
- **ホットキー一覧**

### 設定タブ

- **OBS用に起動時パネル非表示**: 配信用
- **デフォルトに戻す**: 全設定リセット（画像も消えます）
- **JSONで書き出し**: 現在の全設定（画像 dataURL 含む）をファイル保存
- **JSONを読み込み**: 別環境で書き出した設定を取り込み（PCの引き継ぎや友達への共有に）

## ホットキー

| キー | 動作 |
|---|---|
| Space (押下中) | 驚き顔 |
| H | パネル開閉 |
| Y | よそ見を強制発火 |

OBS のブラウザソース上ではキーボード入力が届かないので、OBS のホットキー設定や、ブラウザソースの「インタラクト」モード経由でないと反応しないことがあります。

---

## 設定の保存場所

設定は **ブラウザの localStorage と IndexedDB**（オリジン: `http://localhost:8765`）に分けて保存されます。

- 軽い設定（閾値・モーション値等）: localStorage
- 画像データ: IndexedDB（容量の大きい方）に PNG dataURL として保存
- ブラウザのキャッシュ/サイトデータを全削除すると両方消えます
- 別 PC に引き継ぐ時は「JSONで書き出し」→ 別PCで「JSONを読み込み」（画像も含めて1つのJSONになります）
- OBS のブラウザソースも独自の保存領域を持つので、Chrome で設定しても OBS には反映されません（**OBS のブラウザソースで開いて設定する**のが基本）

## トラブルシューティング

### マイク許可が降りない

- **OBS のブラウザソース**: 上述の起動フラグ（`--use-fake-ui-for-media-stream`）が必須です
- **Chrome/Edge**: アドレスバー左の鍵アイコンから「マイク」を「許可」に設定 → ページ再読み込み
- **debug 表示** が `NotAllowedError` → 上記を確認
- **debug 表示** が `protocol=file:` → `file://` で開いている。サーバー経由で http://localhost:8765/ で開いてください

### 設定が消える

- ブラウザのキャッシュ削除や、シークレットモードでは保存されません
- 画像は IndexedDB に保存されるため、通常の使用範囲ではまず容量上限に当たりません

### アバターが表示されない

- 「画像」タブの「通常」スロットに画像が設定されているか確認
- 表示直後は debug 欄を確認、何らかのエラーが出ていれば対処

### OBS でアバターが小さい/大きい

- OBS 側のブラウザソースの「幅」「高さ」を調整するか、シーン内で右クリック →「変換」→「画面に合わせる」など
